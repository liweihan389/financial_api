# 股市财务与日度行情插件

版本0.3.1，通过21个MCP工具连接本机服务。保留季度财务查询，并增加日度价格、日度PE/PB/PS、技术指标、收益回撤、筛选及CSV/Parquet导出。插件包不含原始数据或数据库。

按应用包README启动服务，安装插件后刷新插件列表或打开新聊天。服务地址 http://127.0.0.1:8765/mcp；管理网页 http://127.0.0.1:8765/ui；接口说明 http://127.0.0.1:8765/docs。

先查看数据状态：本地行情为代表性样本，不是完整市场历史；当前工具并非实时行情。证券使用PERMNO消歧，财务使用GVKEY。通用前复权和后复权默认含股息总收益；技术图与技术分析默认排除普通现金股息，用户指定basis优先。收益风险默认总收益。新增get_adjusted_prices工具提供复权OHLC，adjustment=forward/backward控制方向，purpose=general/technical控制用途默认值。历史财务是近似口径，日度披露生效设为下一观察交易日。

报价币种和ADR每股尺度保留研究假设及质量标记；ADR不二次换算比例。证券匹配、单位、半年EPS或混合股类有问题时相应估值为空并说明原因。使用远程服务时，把mcp.json的地址改为部署地址，并配置Authorization: Bearer访问令牌；服务部署说明见应用包DEPLOYMENT.md。

SEC 新期间补充从财务期末日晚于2026-02-28起，普通财务请求默认combined，供应商同期间整期优先。新增状态、原始事实、字段映射、待核项和后台同步工具。研究模式可用推断候选，historical_approx排除推断字段；不把ADR假定或来源混合作为已验证数据。SEC_USER_AGENT未配置时，联网和每日北京时间20:00更新未启用，离线JSON/ZIP仍可导入。只补财务，不补新行情。复现同时固定两源代次、规则版本和软件版本。详细操作见应用包SEC.md。
